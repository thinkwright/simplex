# Simplex fidelity pilot v1 archive

This directory is the complete archive of a 162-cell, Simplex-only controlled engineering pilot
run on 2026-07-19. It contains the frozen protocol, task and grader sources, generated prompts,
reference implementations, raw model transcripts and workspaces, requirement-level scorecards,
derived tables, and five SVG figures.

Start with [`EXPERIMENT.md`](EXPERIMENT.md) for the comprehensive experiment record, results,
limitations, data dictionary, and reproduction notes. [`PROTOCOL.md`](PROTOCOL.md) is the unchanged
pre-inference protocol. [`analysis/1784490337/RESULTS.md`](analysis/1784490337/RESULTS.md) is the
concise report generated by the frozen analyzer.

Every agent prompt was a Simplex v0.6 document. There was no prose condition. The results describe
execution fidelity under these specifications and cannot establish a representation effect.

## Archive summary

- 6 task families
- 3 variants per family: one base and two single-requirement mutations
- 3 models and 3 trials
- 162 recorded cells, including 3 prespecified timeout failures
- 159 completed graders
- 1,863 requirement observations
- 2,214 declared example-requirement calibration observations
- 142 clean resource-eligible cells

ThinkBench remains an external dependency and was not modified by this study. The post-run
[`archive-manifest.json`](archive-manifest.json) provides a SHA-256 and byte count for every retained
experiment file except itself. Interpreter and package-manager caches are intentionally excluded.

This archive is separate from the earlier paired-prompt engineering run in
`research/thinkbench-pilot-v1`; results from the two studies must not be pooled.
