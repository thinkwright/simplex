## Summary

Created the `detreport` package from scratch with three files:

- **`detreport/__init__.py`** — re-exports `build_report` and `ReportError` from `detreport.public` (allowed since it's detreport itself).
- **`detreport/public.py`** — the public API. `ReportError` exception and `build_report(events)`:
  - Validates the collection is a list and each event is a dict with *exactly* `id`, `category`, `amount_cents`; `id` is a unique non-empty string, `category` a non-empty string, `amount_cents` an integer that is **not** a bool (bool is rejected before the `int` check). All validation runs before any grouping, so invalid input raises `ReportError` without mutating input.
  - Groups by category into objects with exactly `category`, `count`, `total_cents`, `events` (ids sorted ascending); orders groups by category in **descending** Unicode code-point order; computes `grand_total_cents` as the sum of all event amounts. Input events are only read, never mutated.
  - Returns compact JSON via `json.dumps(..., ensure_ascii=False, sort_keys=True, separators=(",", ":"))`, yielding exactly `grand_total_cents` and `groups` at top level with sorted keys everywhere.
- **`detreport/__main__.py`** — CLI: `python -m detreport INPUT_JSON` reads a JSON array from the path, prints exactly `build_report` output plus one newline, exits 0 on success and non-zero with a descriptive stderr message on error.

Only the standard library (`json`, `sys`) and `detreport` itself are imported (C1/E7).
