## How it satisfies the rules
- **R1**: `Bucket(capacity, refill_per_second, clock=None)` starts full (`self._tokens = capacity`); default clock is `time.monotonic`.
- **R2**: `allow(amount=1)` refills first, consumes and returns `True` when `tokens >= amount`, else returns `False` without consuming.
- **R3**: refill computes `elapsed = now - last`, clamps negative (backward clock) to `0`, caps balance at `capacity` via `min`.
- **R4**: the balance is never rounded; fractional results are kept exactly (e.g. `0.5 * 3 == 1.5`).
- **R5**: `available()` runs the same `_refill()` and returns the balance without consuming.
- **R6 / X1**: `_validate_number` rejects booleans and non-numerics, enforces `capacity > 0`, `refill_per_second >= 0`, `amount > 0`; all raise `ValueError`. Invalid `allow` amounts are validated before acquiring the lock, so no tokens are consumed.
- **R7 / C1**: a `threading.Lock` guards `allow`/`available`; only `threading` and `time` (standard library) are imported, and all elapsed-time decisions call the supplied clock.
