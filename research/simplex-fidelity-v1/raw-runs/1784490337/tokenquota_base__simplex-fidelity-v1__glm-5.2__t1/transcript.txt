## Summary

I created the `tokenquota` package from scratch with two files:

- **`tokenquota/__init__.py`** — re-exports `Bucket` from `tokenquota.public` so both `from tokenquota import Bucket` and `from tokenquota.public import Bucket` work.

Key implementation details satisfying the contract:
- **R1/D1**: `Bucket(capacity, refill_per_second, clock=None)` starts full (`_tokens = capacity`); default clock is `time.monotonic`.
- **R2**: `allow(amount=1)` refills first, then consumes and returns `True` only when enough tokens exist; otherwise returns `False` without consuming.
- **R3**: refill is `elapsed * refill_per_second` capped at `capacity`; backward clock movement is clamped to zero elapsed time (`if elapsed < 0: elapsed = 0`).
- **R4**: the balance is never rounded — `min(capacity, tokens + elapsed * rate)` keeps fractional tokens exactly.
- **R5**: `available()` runs the identical refill calculation and returns the balance without consuming.
- **R6/X1**: validation rejects non-numbers and booleans; `capacity <= 0`, `refill_per_second < 0`, and a non-positive or boolean `amount` raise `ValueError` before any tokens are touched.
- **R7**: all access to `_tokens`/`_last` is serialized by a `threading.Lock`, so concurrent successful consumption never exceeds available tokens.
- **C1**: every elapsed-time decision calls the supplied `clock()`; only `threading` and `time` are imported (verified by AST-scanning the source).
