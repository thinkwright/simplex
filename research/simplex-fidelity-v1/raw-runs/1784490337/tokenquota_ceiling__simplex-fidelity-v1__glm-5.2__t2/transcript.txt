## Summary

I created the `tokenquota` package with two files:

- **`tokenquota/__init__.py`** — re-exports `Bucket` from `tokenquota.public` so both `from tokenquota.public import Bucket` and `from tokenquota import Bucket` work.
- **`tokenquota/public.py`** — implements `Bucket(capacity, refill_per_second, clock=None)` using only the standard library (`math`, `threading`, `time`).

Key implementation points:
- **R1**: starts full (`balance = capacity`); defaults `clock` to `time.monotonic` when none is supplied, and uses *only* that clock for all elapsed-time decisions (C1).
- **R2/R5**: `allow(amount=1)` and `available()` share a `_refill()` helper that adds `elapsed * refill_per_second`, clamps to capacity, and (only when elapsed > 0) rounds the balance up via `math.ceil` without exceeding capacity (R4). `allow` consumes and returns `True`/`False`; `available` returns the balance without consuming.
- **R3**: backward clock movement is treated as zero elapsed time and does *not* advance the reference point, so a backward-then-forward round trip never grants tokens for the negative portion; balance never exceeds capacity.
- **R6/X1**: validates `capacity > 0`, `refill_per_second >= 0`, and `amount > 0` and not a boolean (rejecting `True`/`False`), raising `ValueError` without consuming tokens on invalid input.
- **R7**: a `threading.Lock` serializes `allow`/`available`, so concurrent successful consumption never exceeds available tokens.
